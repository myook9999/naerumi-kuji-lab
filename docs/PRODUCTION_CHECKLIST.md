# 납품 전환 체크리스트

현재 저장소는 시연용입니다. 실제 납품판에서는 아래 항목을 완료하고 별도 검수를 진행해야 합니다.

1. Firebase 운영 프로젝트와 관리자 SDK를 연결하고 Firestore 보안 규칙·인덱스를 배포합니다.
2. 데모 로그인 대신 Firebase Auth 또는 검증된 인증 공급자를 사용하고, 서버에서 매 요청의 역할과 지점 권한을 확인합니다.
3. 정산·포인트·강화·배송 이벤트를 트랜잭션으로 영구 저장하고 감사 로그와 복구 정책을 적용합니다.
4. 쿠지 프로그램별 HMAC 비밀키를 Secret Manager에 보관하고 키 교체·재전송·장애 복구 절차를 구성합니다.
5. 실제 결제/택배 API는 테스트 환경에서 계약 명세와 개인정보 보존 정책을 확인한 뒤 연결합니다.
6. 관리자 작업의 접근 제어, 입력 검증, 속도 제한, 개인정보 마스킹을 보안 검수합니다.
7. 스테이징에서 단위·통합·E2E·모바일·접근성 테스트를 통과한 빌드만 운영에 배포합니다.

시연 중 “실시간”, “연동 정상” 표시는 목업 상태입니다. 고객에게 운영 연동 완료로 안내하면 안 됩니다.
